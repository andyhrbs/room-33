# Room 33

Le site perso d'Andyh pour partager ses goûts musicaux : une pièce d'écoute mid-century où chaque objet mène à une partie du site.

## Lancer le projet

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # génère le site dans dist/
```

## Stack

- [Astro](https://astro.build) pour le site
- Netlify pour l'hébergement, les fonctions (Spotify, Deezer, Odesli) et les formulaires
- Sveltia CMS sur `/admin` pour ajouter les disques, les bacs et le Top
